# DeepSeek 对话导出器

这是一个为 DeepSeek 官网定制的浏览器插件。

## ✨ 功能特性

本插件经过精心设计与反复调试，以确保最大程度的准确性和灵活性，其核心功能包括：

- **一键导出**：在DeepSeek对话页面，通过点击插件图标即可轻松导出当前完整对话。
- **完整格式保留**：能够精准解析并转换AI回答中的所有富文本格式，包括：
  - `**加粗**` 与 `*斜体*`
  - 无序列表、有序列表（包括多级**嵌套列表**）
  - `> 引用块`
  - `---` 分隔线
  - `### 标题`
  - **Markdown表格**
  - **代码块**（自动识别并标注语言类型）
- **完美的公式处理**：
  - 能够100%准确地提取所有**行内公式**与**块级公式**的原始LaTeX源码。
- **自定义公式风格**：
  - 可以在导出时自由选择公式的渲染风格，以适应不同的Markdown编辑器：
    - **通用 Markdown 风格**：行内 `$...$`，块级 `$$...$$`
    - **标准 LaTeX 风格**：行内 `\(...\)`，块级 `\[...\]`
-  **智能文件命名**：自动抓取当前对话的标题作为下载的 `.md` 文件名，方便整理。
-  **稳定可靠的架构**：最终版本采用读取浏览器本地数据库（IndexedDB）的方式直接获取原始数据，从根本上避免了因网站前端页面结构变化而导致插件失效的问题，具有极高的稳定性。

## 🚀 安装与加载

本插件是一个标准的Chrome浏览器扩展（Manifest V3），可以轻松在任何基于Chromium内核的浏览器（如 Chrome, Edge）中加载使用。

1. **下载项目文件**：将本项目的所有文件（`manifest.json`, `content.js`, `popup.html`, `popup.js`, `icons/`文件夹）保存在电脑的同一个文件夹内，例如 `deepseek_exporter`。
2. **打开扩展管理页面**：
   - 在浏览器地址栏输入 `chrome://extensions` (Chrome) 或 `edge://extensions` (Edge)。
3. **启用开发者模式**：
   - 在页面右上角，找到并打开 **“开发者模式”** 的开关。
4. **加载插件**：
   - 点击页面左上方出现的 **“加载已解压的扩展程序”** 按钮。
   - 在弹出的文件选择窗口中，选择在第一步中创建的**整个 `deepseek_exporter` 文件夹**。
5. **完成**：如果一切顺利，将在浏览器右上角的工具栏看到本插件的图标，表示加载成功。

## 📝 文件结构

```
deepseek_exporter/
│
├── manifest.json         # 插件配置文件，定义权限、脚本和行为
├── content.js            # 核心脚本，负责从IndexedDB提取和处理数据
├── popup.html            # 弹出窗口的HTML结构和样式
├── popup.js              # 弹出窗口的交互逻辑脚本
│
└── icons/                # 插件图标文件夹
    ├── icon16.png
    ├── icon48.png
    └── icon128.png
```
